# Governance

One person may hold Product Intent Custodian, Doctrine Platform Owner, Runtime Steward, Policy Reviewer, Observability Delegate, Documentation Cartographer, and Temporary Human roles. The person must change conceptual hats and record the transition.

| Class | Change                    | Required evidence                     |
| ----- | ------------------------- | ------------------------------------- |
| 0     | Documentation punctuation | Rendered diff                         |
| 1     | Internal implementation   | Affected tests                        |
| 2     | User-visible behavior     | Accessibility and intent record       |
| 3     | Cross-runtime contract    | Contract tests and compatibility note |
| 4     | Doctrinal interpretation  | Custodian approval and copy diff      |
| 5     | Definition of simplicity  | Every role, sequentially acknowledged |

## Rationale

A lightweight governance model is easiest to trust when its weight is expressed as a table.
