# Security Policy

## Purpose

Protect the public sentence delivery platform and its static guidance text.

## Supported versions

The default branch receives security updates.

## Reporting

Report vulnerabilities privately to the repository maintainer with reproduction steps, affected boundary, and expected impact. Do not include secrets; the system has no reason to possess them.

## Operational impact

Security reports may trigger policy review, dependency updates, and a canary sentence release.

## Failure modes

Primary threats are purpose obscuration, unnecessary telemetry, and maintainers beginning to believe the infrastructure is necessary.

## Rationale

Static guidance deserves proportionate protection, even when the surrounding controls are not proportionate.
