# Web Agent Constraints

- Do not place direct text literals in components; source visible copy from controlled packages.
- Do not access environment variables outside designated adapters.
- Do not make network calls outside the doctrine adapter.
- Keep components below a modest line limit.
- Add a story for each new component and an interaction assertion when meaningful.
- Attach accessibility evidence to visible changes.
- Reference an incident class for new fallback behavior.
- Do not delete complexity without an ADR proving it has ceased to provide strategic optionality.

## Rationale

The presentation surface remains calm only when its development process absorbs the anxiety.
