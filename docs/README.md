# Documentation Control Plane

## Purpose

Route readers toward architecture, operations, delivery, product, governance, and AI-assisted change knowledge.

## Scope

All documents that explain why one page requires several navigation domains.

## Non-goals

This index does not reveal the original intent directly.

## Operational impact

Documentation changes participate in rationale governance.

## Failure modes

Readers may arrive at the answer before selecting a role.

## Rationale

The maze is navigable, which is more defensible than making it short.
