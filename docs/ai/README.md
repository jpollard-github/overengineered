# AI-Assisted Change

## Purpose

Constrain automated interpretation while preserving the user's wording and objective.

## Scope

Inspection, records, classification, implementation, evidence, and drift checks.

## Non-goals

The process does not authorize broader scope.

## Operational impact

Agents must explain why direct implementation may remain direct.

## Failure modes

Instructions may bury the judgment they claim to protect.

## Rationale

Automation should remain accountable to the actual artifact and visible failure.
