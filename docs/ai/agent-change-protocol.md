## Scope

Class 1 through 5 changes and any correction loop.

## Non-goals

Templates do not broaden authority.

## Operational impact

When repeated correction occurs, open an Interpretation Incident Record.

## Failure modes

Records can become substitutes for reading.

## Rationale

Interpretive failures need evidence without automatically needing new architecture.
