# Evidence Requirements

## Purpose

Define proof proportional to change surface.

## Scope

Tests, builds, accessibility, contracts, health, and purpose checks.

## Non-goals

Evidence cannot prove that an unrequested change was authorized.

## Operational impact

Both Nx and Turbo report affected execution.

## Failure modes

Large evidence packets may obscure a small visible failure.

## Rationale

Verification should be proportional even when the repository is not.
