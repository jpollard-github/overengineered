# Prompt Boundaries

## Purpose

Keep agent action within explicit user scope.

## Scope

User wording, artifacts, requested changes, and verification.

## Non-goals

Adjacent opportunity is not implicit authorization.

## Operational impact

Agents stop when the requested change is complete and evidence is assembled.

## Failure modes

Reasonably foreseeable reuse may tempt premature packaging.

## Rationale

Preserving intent is more important than demonstrating initiative.
