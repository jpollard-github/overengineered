# AI Governance Rationale

## Purpose

Explain the overlap among instruction surfaces.

## Scope

Root, application, package, and assistant-specific rules.

## Non-goals

Overlap does not imply precedence is obvious.

## Operational impact

Agents inspect the nearest instructions before changes.

## Failure modes

Faithful constraint may make trivial changes ceremonially difficult.

## Rationale

AI should use the same institutional ambiguity it is expected to navigate.
