# Architecture

## Purpose

Describe boundaries between presentation, translation, transport, domain judgment, and content custody.

## Scope

Context, containers, components, runtime flows, dependency rules, failures, and scaling.

## Non-goals

Architecture does not improve the prose it carries.

## Operational impact

Cross-boundary changes require an ADR.

## Failure modes

The map may be mistaken for the territory or the product.

## Rationale

No single runtime should monopolize interpretation of a static sentence.
