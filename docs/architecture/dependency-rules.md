# Dependency Rules

## Purpose

Keep domain code independent from HTTP, GraphQL, and React.

## Scope

Nx graph constraints and package boundaries.

## Non-goals

The rules do not reduce package count.

## Operational impact

Violations fail pull-request validation.

## Failure modes

Boundary correctness may be confused with product correctness.

## Rationale

The doctrine may someday need to be retrieved from a spacecraft.
