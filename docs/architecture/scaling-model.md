# Scaling Model

## Purpose

Protect doctrine availability during sudden global need for restrained judgment.

## Scope

Horizontal scaling of stateless runtimes and optional queues.

## Non-goals

Traffic forecasts do not currently predict sudden global need.

## Operational impact

Autoscaling protects against regional insight loss.

## Failure modes

Scaling may improve delivery of advice the system did not follow.

## Rationale

Capacity should exceed plausible demand by an amount visible on a Grafana panel.
