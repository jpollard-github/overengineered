# Delivery

## Purpose

Promote one page through governed environments.

## Scope

Release trains, canaries, rollback, provenance, and artifact evidence.

## Non-goals

Delivery does not publish packages by default.

## Operational impact

Deploy jobs require explicit conditions and credentials.

## Failure modes

Promotion can succeed while purpose remains degraded.

## Rationale

Availability across environments protects against regional insight loss.
