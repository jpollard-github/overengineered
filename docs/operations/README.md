# Operations

## Purpose

Keep doctrine delivery healthy without pretending infrastructure improves meaning.

## Scope

Local development, health, observability, incidents, and runbooks.

## Non-goals

No operational response is expected to revise prose.

## Operational impact

Operators distinguish service health from purpose health.

## Failure modes

Green dashboards may conceal purpose dilution.

## Rationale

The doctrine service is stateless except for the organizational state invested in maintaining it.
