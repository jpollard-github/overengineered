# Runbook: Distributed Meaning Degradation

## Purpose

Recover when every layer is healthy but nobody remembers why it exists.

## Scope

Purpose records and interpretation evidence.

## Non-goals

Do not restart Kubernetes as a substitute for reading.

## Operational impact

Run `pnpm purpose:check` and follow the history maze.

## Failure modes

The original record may be found and ignored.

## Rationale

Organizational state requires recovery procedures even when runtime state is empty.
