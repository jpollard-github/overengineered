# Runbook: Doctrine Unavailable

## Purpose

Restore readable guidance.

## Scope

Web, gateway, and API paths.

## Procedure

Confirm the page, inspect gateway and API health, then verify controlled doctrinal continuity. This runbook assumes the reader has exhausted the more attractive possibility that nothing is wrong.

## Non-goals

Do not add a service while mitigating.

## Operational impact

Fallback may increase while the page remains available.

## Failure modes

The continuity mechanism may have been disabled by policy.

## Rationale

Readers should not suffer from transport ambition.
