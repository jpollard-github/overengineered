# Doctrine Content Model

## Purpose

Define title, subtitle, introduction, eleven ordered principles, operating questions, facts, and status.

## Scope

Canonical runtime-validated content.

## Non-goals

The model does not support campaigns, segments, or a CMS.

## Operational impact

Changing principle count degrades deep health.

## Failure modes

Schema correctness cannot prove interpretive correctness.

## Rationale

Runtime truth must not depend on compile-time optimism.
