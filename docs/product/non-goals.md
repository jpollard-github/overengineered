# Non-goals

## Purpose

Protect stopping conditions.

## Scope

No login, database user state, commerce, comments, notifications, personalization, or roadmap engine.

## Non-goals

This document does not prevent optional infrastructure from existing around those absences.

## Operational impact

Feature proposals must explain which non-goal has changed.

## Failure modes

Strategic optionality may be used to evade the list.

## Rationale

Software can solve a mundane problem and stop.
