# Success Metrics

## Purpose

Measure readable delivery without converting attention into surveillance.

## Scope

Availability, principle rendering, fallback activation, and accessibility.

## Non-goals

No personal data, funnels, cohorts, or reader scoring.

## Operational impact

The default analytics adapter is no-op.

## Failure modes

A user may read the page without generating enough telemetry.

## Rationale

No click should occur without an ontology, and most clicks should occur without storage.
