# Infrastructure

## Purpose

Provide credible deployment scaffolding without requiring cloud credentials for local success.

## Scope

Docker, Helm, Kustomize, Terraform, Argo CD, observability, and policy.

## Non-goals

These files are not evidence that a Kubernetes cluster is necessary.

## Operational impact

Core page delivery does not depend on Redis or observability services.

## Failure modes

Operators may mistake scaffolding for obligation.

## Rationale

High availability protects the doctrine from regional insight loss.
