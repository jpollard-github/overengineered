# Kustomize

## Purpose

Express environmental dissent after Helm defines deployable intent.

## Scope

Local, development, staging, production, and executive-demo overlays.

## Non-goals

Kustomize does not replace Helm or resolve the disagreement.

## Operational impact

Each overlay adjusts scale and image identity.

## Failure modes

Two correct renderers may produce differently correct YAML.

## Rationale

No environment should accept centralized configuration without a patch.
