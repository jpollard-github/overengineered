# Threat Model

## Assets

- Primary: static guidance text.
- Secondary: integrity of ordering and purpose records.

## Threats

- Architecture obscures purpose.
- A user reads the page without generating enough telemetry.
- Maintainers begin believing the infrastructure is necessary.
- Policy or transport prevents public content display.

Privacy risk is minimal because no personal data is stored.

## Rationale

The most credible threat is organizational, so it must be documented near the network policies.
