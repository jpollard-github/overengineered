# Independently Versioned Sentence Protocol

Any modification to the exported sentence requires:

1. Product intent review.
2. Copy diff.
3. Semantic compatibility assessment.
4. Snapshot update.
5. Contract version review.
6. Changeset.
7. Documentation impact statement.
8. Localization readiness note.
9. Rollback plan.
10. Proof the new sentence remains one line at supported viewport widths, despite responsive footer rendering.

## Rationale

High-value language deserves independent versioning and a rollback path to its previous punctuation.
